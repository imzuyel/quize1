# PGTSC Quiz Arena — Classroom Final v9

This release focuses on the product's core goal: a polished, low-friction Kahoot/Mentimeter-style classroom quiz platform.

## Student join
- Home page keeps a prominent Join Quiz CTA at the top.
- Join accepts either a numeric Game PIN or a keyword.
- Nickname is optional.
- If nickname is blank, the server generates a friendly nickname such as `স্মার্ট পান্ডা 47`.
- Existing player reconnect support remains enabled.

## Classroom UX
- Host lobby shows PIN, keyword and QR join flow.
- Student lobby shows live participant count and waiting state.
- Live question, timer, answer feedback, leaderboard and final podium remain available.
- Presentation/fullscreen mode and keyboard controls remain available.

## Visual system
- Bangla-first typography using Hind Siliguri + Noto Sans Bengali, with Inter for Latin UI.
- Light/dark color system and animated theme components are retained.
- SVG/vector icons and animated surfaces are retained.
